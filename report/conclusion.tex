\chapter{Conclusion and Work Plan}\label{ch:concl}

This midterm report has defined the research problem, reviewed the relevant
literature, and described the current implementation of a structured
communication MARL controller for CityLearn. The project fits into a clear gap:
CityLearn provides a strong building-energy benchmark, MAPPO provides a
practical CTDE backbone, and communication methods provide coordination tools,
but the effect of structured communication for portfolio-level CityLearn load
tracking still needs systematic study.


Significant implementation work has been completed. The codebase now includes
independent PPO/SAC baselines, standard MAPPO, grouped MAPPO, K-means-based
building grouping, and several communication-aware grouped MAPPO variants,
including CommNet, weighted communication, PowerNet, TarMAC, DIAL, and GAT. The
communication modules are integrated into the actor pipeline and can be trained
through the standard PPO objective. The evaluation pipeline now exports Annex 96
metrics together with ranking tables and load-tracking figures, and the selected
Vermont benchmark result set has been completed. The current CE1 data does not
provide pricing or carbon-intensity time series, so cost and carbon fields are
kept as unavailable rather than interpreted as algorithm performance.


The main conclusion at this stage is clear. Architecturally, grouped
MAPPO with modular communication is a feasible and well-supported research
direction for the CityLearn portfolio. Numerically, the completed Vermont
benchmark results show that communication clearly changes the trade-off between
tracking, reward, comfort, and secondary metrics. The strongest overall Vermont
result is currently
\texttt{mappo\_grouped\_powernet\_global\_vt\_500\_final2}. At the same time,
the ranking tables show that the answer depends on which objective mix
is emphasized: the default weighted communication setting leads the
primary-only ranking, while the independent PPO baseline leads the
recommended-score table but uses a shorter training budget and therefore serves
mainly as a supplementary reference. TarMAC and the weighted
\mbox{$\alpha=0.90, \beta=0.10$} setting remain strong MAPPO-family competitors.


\section{Next Steps}

The work plan for the next stage is:


\begin{itemize}
  \item extend the completed Vermont comparison to Texas so that conclusions can
  be tested in both heating-dominated and cooling-dominated conditions;
  \item add multi-seed evaluation for the strongest methods, especially standard
  MAPPO, grouped MAPPO, PowerNet Global, TarMAC, weighted communication, and
  CommNet;
  \item compare the current MAPPO backbone with other MARL families such as
  SAC/MASAC and value-based methods;
  \item analyse aggregate load tracking, comfort, ramping, battery behaviour,
  and fairness in more detail, and include cost or emissions only if valid
  price and carbon-intensity signals are supplied;
  \item explain more clearly why the best communication variants outperform the
  weaker ones;
  \item refine the final report with the completed Texas results, additional
  sensitivity tests, and a concise discussion of limitations.
\end{itemize}

If time allows, additional work will test sensitivity to the number of clusters,
communication rounds, and weighted communication coefficients. A further
extension is to learn building embeddings for grouping instead of relying only
on static flexibility features.
