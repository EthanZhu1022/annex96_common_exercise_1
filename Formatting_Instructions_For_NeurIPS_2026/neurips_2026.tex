\begin{abstract}
Coordinating flexible buildings requires both information exchange and policy
specialization. We study this interaction on the 25-home IEA EBC Annex~96
Common Exercise~1 load-tracking task in CityLearn. Preliminary experiments
compare independent PPO and SAC, grouped MAPPO without communication, and a
broad set of communication mechanisms. They show that communication can be
either useful context or noise, motivating TarMAC Hybrid: state-dependent
attention followed by a compressed local/message fusion and residual update.
We then place a multi-stage Soft Router above five complete TarMAC-aware actor
experts. TarMAC tells the router what is happening across the portfolio; the
router decides which specialized encoder--communication--head branch should
control each building at that time. On the Vermont February test, the selected
Soft Router obtains 45.25\% CV-RMSE, 1.06\% absolute NMBE, and 16.45\% comfort
exceedance, compared with 47.01\%, 3.51\%, and 17.99\% for TarMAC Hybrid and
51.50\%, 2.75\%, and 20.95\% for no-communication grouped MAPPO. Independent
PPO retains the best mean comfort, and the router's worst building still
violates the comfort band for 551 hours. The result is therefore a stronger
portfolio controller, not evidence of deployment-ready per-building safety.

\section{Introduction}

% 中文小节：引言
%

An aggregator can coordinate batteries and heating, ventilation, and air
conditioning (HVAC) so that a community follows a portfolio reference load.
Each home observes different demand, thermal state, and flexibility, but the
tracking objective depends on their sum. Independent control may protect local
objectives yet cannot explicitly reason about the aggregate error; cooperative
MARL can optimize the portfolio but risks hiding poor individual outcomes.
CityLearn provides a reproducible closed-loop environment for this problem
\citep{citylearn2020,citylearnv2}, and MAPPO provides a stable
centralized-training/decentralized-execution backbone \citep{mappo2022}.

% 中文：
%   聚合商可以协调社区内的电池和暖通空调（HVAC），
%   使整个社区跟踪给定的组合参考负荷。
%   每栋住宅看到的需求、热状态和灵活性不同，
%   但负荷跟踪目标取决于所有住宅负荷之和。
%   个体控制可能更容易保护局部目标，
%   却无法显式分析整个组合的跟踪误差；
%   合作式 MARL 可以优化组合目标，
%   但也可能掩盖某些建筑的不良结果。
%   CityLearn 为该问题提供可复现的闭环环境，
%   MAPPO 则提供相对稳定的集中训练、分散执行主体结构。
%

The first stage of this project compared independent PPO/SAC
\citep{ppo2017,haarnoja2018sac}, standard and grouped MAPPO,
no-communication control, CommNet-style averaging, fixed
same-/other-group weighting, GAT, DIAL, PowerNet-style structured exchange, and
TarMAC attention. No mechanism dominated every metric. Fixed-weight ablations
showed that cross-group information changes from gain to noise as the weight
changes; PowerNet-style results suggested that useful local features should be
preserved rather than overwritten. TarMAC was the most extensible direction
because it learns a different communication weight for every sender, receiver,
and state instead of imposing a fixed average \citep{tarmac2019}. We retained
that adaptive attention and incorporated the two lessons above in TarMAC
Hybrid.

%   项目前期比较了个体 PPO/SAC、标准和 grouped MAPPO、
%   无通信控制、CommNet 式平均通信、固定的组内/组外加权、
%   GAT、DIAL、PowerNet 式结构化信息交换和 TarMAC attention。
%   没有一种通信机制在所有指标上都占优。
%   固定权重消融表明，随着组外消息权重变化，
%   跨组信息可能从增益变成噪声；
%   PowerNet 类实验则说明，有用的局部特征不应被通信覆盖。
%   我们最终选择 TarMAC 作为继续开发的方向，
%   因为它不使用固定平均权重，
%   而是针对不同发送者、接收者和当前状态学习不同通信权重。
%   TarMAC Hybrid 保留这种自适应 attention，
%   同时吸收了前述两个前期实验结论。
%

Communication alone still leaves a second restriction. Grouped MAPPO assigns
each building permanently to one actor, although the most appropriate policy
may change with state of charge, thermal demand, and portfolio conditions.
Mixture-of-experts methods provide conditional specialization
\citep{puigcerver2024softmoe,obandoceron2024moerl}; here we use this idea to
route complete control policies rather than feed-forward sublayers. The paper
therefore follows one experimental chain:
\emph{independent control $\rightarrow$ cooperative MAPPO $\rightarrow$
TarMAC Hybrid communication $\rightarrow$ multi-stage expert routing}.

%   仅有通信仍存在第二个限制。
%   Grouped MAPPO 会把每栋建筑永久分配给同一个 actor，
%   但最合适的策略可能随 SOC、热需求和组合工况变化。
%   Mixture-of-experts 提供条件专业化思想；
%   本文把该思想用于路由完整控制策略，
%   而不是只路由前馈网络中的子层。
%   因此，论文围绕一条清楚的实验链展开：
%   个体控制 → 合作式 MAPPO → TarMAC Hybrid 通信
%   → 多阶段专家路由。
%

\section{TarMAC Hybrid: why communication helps}

% 中文小节：TarMAC Hybrid——通信为什么有帮助
%

\paragraph{Targeted portfolio context.}
For latent state $h_i$, TarMAC forms query, key, and value vectors and sends
building $i$ the attention-weighted context
\begin{equation}
q_i=W_qh_i,\quad k_i=W_kh_i,\quad v_i=W_vh_i,\qquad
c_i=\sum_j
\operatorname{softmax}_j\!\left(q_i^\top k_j/\sqrt{d_k}\right)v_j .
\label{eq:tarmac}
\end{equation}
Unlike independent PPO/SAC, every action can depend on other homes. Unlike
unweighted mean communication, a receiver can emphasize a building with
relevant battery or HVAC flexibility and suppress an irrelevant sender. The
weights also change each hour, which is important when the same building moves
from available flexibility to saturation.

% 中文（有针对性的组合信息）：
%   对隐藏状态 h_i，TarMAC 构造 query、key 和 value，
%   并按照式（1）向建筑 i 发送 attention 加权后的上下文 c_i。
%   与个体 PPO/SAC 不同，每个动作可以依赖其他住宅的状态。
%   与无权重的平均通信不同，接收者可以提高具有相关电池或
%   HVAC 灵活性的建筑权重，并抑制无关发送者。
%   这些权重每小时都会变化；
%   当同一栋建筑从具有可用灵活性变为设备饱和时，
%   这种状态相关性尤其重要。
%

\paragraph{Hybrid fusion preserves local control information.}
The original implementation fed a 256-dimensional local state and a
64-dimensional message directly to fusion, allowing repeated local information
to dominate the smaller message. The best Hybrid variant instead computes
\begin{equation}
\ell_i=\operatorname{ReLU}(W_\ell h_i),\quad
\Delta_i=\tanh\!\left(W_2\tanh(W_1[\ell_i;c_i]+b_1)+b_2\right),\quad
h'_i=h_i+\Delta_i .
\label{eq:hybrid}
\end{equation}
The $256\!\rightarrow\!64$ projection balances local and communicated widths,
ReLU filters the local representation, and the residual path prevents
communication from erasing the original state. In the matched seed-42
experiment, original TarMAC achieved 49.65\% CV-RMSE and 22.10\% comfort
exceedance; Hybrid ReLU improved them to 47.01\% and 17.99\%. Against
no-communication grouped MAPPO, Hybrid reduces CV-RMSE by 8.7\% and mean
comfort exceedance by 14.1\%, although absolute NMBE increases from 2.75\% to
3.51\%. Communication improves the balance, not every metric.

%   原始实现把 256 维局部状态和 64 维通信消息直接送入融合层，
%   大量重复的局部信息可能压过维度较小的消息。
%   最佳 Hybrid 变体改用式（2）的结构：
%   先把局部信息从 256 维压缩到 64 维并通过 ReLU，
%   再与通信信息融合，最后用残差形式加回原始状态。
%   这种 256→64 投影平衡了局部信息与通信信息的宽度，
%   ReLU 对局部表示进行筛选，
%   残差通路则防止通信抹去原始状态。
%   在匹配的 seed-42 实验中，

%   Hybrid 将 CV-RMSE 降低 8.7%，

\section{Multi-stage Soft Router over TarMAC experts}

% 中文小节：建立在 TarMAC 专家之上的多阶段 Soft Router
%

\paragraph{Complementary roles.}
TarMAC and the router solve different questions. TarMAC answers
\emph{what is happening elsewhere in the portfolio?}; the router answers
\emph{which specialized policy should act here now?} Five grouped MAPPO actors
are first pretrained with TarMAC Hybrid. For building $i$, its communicated
256-dimensional feature $h_{it}$ is augmented with seven physical features:
battery capacity, HVAC rating, state of charge, remaining charge space,
available discharge energy, non-shiftable load, and heating demand. A shared
$263\!\rightarrow\!64\!\rightarrow\!5$ router produces
\begin{equation}
d_{it}=\operatorname{softmax}(f_\theta([h_{it};q_{it}])/\tau),\qquad
g_{it}=(1-\alpha)p_i+\alpha d_{it},
\label{eq:gate}
\end{equation}
where $p_i$ is the original fixed-group assignment. TarMAC context therefore
conditions the routing decision; routing does not replace communication.

% 中文（互补作用）：
%   TarMAC 与路由器回答的是两个不同问题。
%   TarMAC 回答“建筑组合中的其他位置正在发生什么？”
%   路由器回答“此时此地应由哪一个专业化策略执行动作？”
%   首先使用 TarMAC Hybrid 预训练五个 grouped MAPPO actor。
%   对建筑 i，把其经过通信后的 256 维特征 h_{it}
%   与七个物理特征组合：
%   电池容量、HVAC 额定功率、SOC、剩余充电空间、
%   可用放电能量、不可转移负荷和供暖需求。
%   共享的 263→64→5 路由器按式（3）输出专家概率，
%   并与原固定分组 p_i 按 α 混合。
%   因此，TarMAC 上下文直接影响路由选择；
%   Soft Router 并不是用来替代通信。
%

\paragraph{Route complete experts.}
Early head-only switching could pair an action head with an encoder on which it
was never trained. The selected design switches the matched
encoder--TarMAC--head branch as one expert. If expert $k$ defines
$\pi_{\phi_k}$, the routed action distribution is
\begin{equation}
\pi_{\theta,\phi}(a_{it}\mid s_t)=
\sum_{k=1}^{5}g_{itk}(\theta)\pi_{\phi_k}(a_{it}\mid s_t).
\label{eq:mixture}
\end{equation}
PPO can update $\theta$ while $\phi$ is frozen because the likelihood of the
executed action still depends on $g_{it}$. Entropy and a batch-level
load-balancing loss discourage one expert from receiving all traffic.

% 中文（路由完整专家）：
%   早期只切换动作头的方案可能把某个动作头
%   与从未和它共同训练的编码器配对。
%   最终设计把匹配的“编码器—TarMAC—动作头”分支
%   作为一个完整专家共同切换。
%   如果专家 k 的动作分布是 π_{φ_k}，
%   完整路由策略就是式（4）所示的混合分布。
%   即使专家参数 φ 被冻结，
%   PPO 仍可更新路由参数 θ，
%   因为已执行动作的概率仍依赖 g_{it}。
%   熵正则和 batch 级负载均衡损失
%   用于抑制全部流量坍塌到同一个专家。
%

\paragraph{Multi-stage stabilization.}
The best schedule starts from the 500-episode Hybrid expert checkpoint. It
trains only the router for 500 episodes with $\tau=0.5$ and
$\alpha:0.5\!\rightarrow\!1$, then freezes the router, encoders, and TarMAC
module and adapts only action heads for 500 episodes at $10^{-5}$. Jointly
changing routing semantics and complete experts caused concentration and
unstable policies; staged freezing turns the pretrained experts into fixed
reference behaviors before allowing a small final adjustment.

% 中文（多阶段稳定训练）：
%   最佳方案从训练 500 个 episode 的 Hybrid 专家 checkpoint 开始。
%   第一阶段只训练路由器 500 个 episode，
%   使用 τ=0.5，并让 α 从 0.5 增长到 1。
%   第二阶段冻结路由器、编码器和 TarMAC，
%   只以 10^{-5} 学习率微调动作头 500 个 episode。
%   同时改变路由含义和完整专家会造成路由集中和策略不稳定；
%   分阶段冻结先把预训练专家变成稳定的参考行为，
%   再允许较小的最终调整。
%

\paragraph{Communication is the first gain.}
Figure~\ref{fig:controller-comparison} shows that no-communication MAPPO has
the weakest CV-RMSE (51.50\%) among the five selected learned controllers.
TarMAC Hybrid lowers this to 47.01\% and reduces mean comfort exceedance from
20.95\% to 17.99\%. This supports the original communication study: the
portfolio target needs cross-building context, but the fusion must filter
messages and preserve local state.

\paragraph{Routing adds conditional specialization.}
The multi-stage router further lowers CV-RMSE to 45.25\%, absolute NMBE to
1.06\%, and mean comfort exceedance to 16.45\%. Relative to Hybrid, these are
3.7\%, 69.8\%, and 8.6\% reductions, respectively. Independent SAC reaches
46.53\% CV-RMSE but has 8.93\% absolute bias and 44.46\% comfort exceedance;
independent PPO gives the best mean comfort (13.74\%) but 49.76\% CV-RMSE.
The routed controller is consequently the strongest balance in this selected
set rather than the winner of every individual objective.

\paragraph{Mean gains do not guarantee local safety.}
The Soft Router's worst home violates the comfort band for 551 hours, compared
with 410 for Hybrid, 384 for no-communication MAPPO, and 314 for independent
PPO. The full temperature traces in Appendix~\ref{app:temperatures} show that a
small number of homes remain above $24^\circ$C for long periods. Appendix
\ref{app:daily} also shows large day-to-day CV-RMSE and NMBE variation.
Communication and routing improve the portfolio average while leaving a
tail-risk problem.

\section{Limitations and conclusion}

% 中文小节：局限性与结论
%

TarMAC and Soft Router are complementary: attention supplies state-dependent
portfolio context to both actions and expert selection, while routing converts
that context into time-varying policy specialization. The strongest design is
also conservative---it preserves complete pretrained TarMAC experts and
separates router learning from head adaptation. However, the final router runs
reuse one strong expert checkpoint, training budgets are unmatched, and the
study contains only 25-building simulations. The Texas stress test in Appendix
\ref{app:climate} retrains the design and therefore does not establish
zero-shot out-of-distribution robustness. CityLearn enforces device dynamics
but contains no distribution-network or AC power-flow model. Future evaluation
should pair complete-training seeds, test unseen portfolios and target
profiles, add tail-aware comfort constraints, and couple the controller to
network feasibility checks.

%   TarMAC 与 Soft Router 具有互补关系：

%   最强方案也相对保守：
%   它保留完整的预训练 TarMAC 专家，
